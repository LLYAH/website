What is a drinking glass set?

A set is four or six matched glasses in one design, bought so that a table looks like a table rather than a collection of whatever survived. Buying as a set costs less per glass than buying singles, and it is the only way to get a matched batch, since etched glass varies slightly between production runs.

Sets in this collection

  • Matched four-piece sets — one design, four identical glasses.
  • Six-piece family sets — sized for a full table.
  • Mixed verse sets — four different passages in one type treatment.
  • His and hers pairs — two glasses in one palette.
  • Wedding and housewarming sets — boxed with a card, ready to give.

Sizes and consistency

Sets are cut and etched together in one run, which is what keeps the etch depth and placement consistent across every glass. Ordering four singles separately will not guarantee the same.

  • Set sizes — four or six glasses.
  • Glass options — 16oz pint, 12oz rocks, or 15oz stemless.
  • Etched together in one run — consistent depth and placement.
  • Rigid boxed — molded insert, safe to ship and to give.
  • Dishwasher safe — all glasses and all etching.

Drinking glass set questions, answered

How many glasses come in a set?

Four or six, depending on the set. Six-piece sets are sized for a full family table.

Why buy a set instead of singles?

Lower cost per glass, and the glasses are etched together in one run, which keeps the depth and placement consistent.

Can I mix glass types in one set?

Not within a single set. Sets are one shape. Order two sets if you want pint and rocks glasses together.

What is a mixed verse set?

Four different passages set in one consistent type treatment, so they read as a family rather than as four unrelated glasses.

Can I order a replacement glass later?

Yes. A replacement from a different run may vary very slightly in etch depth, which is inherent to sandblast etching.

Do sets arrive gift-ready?

Yes. Every set ships in a rigid box with a molded insert and a blank card.
