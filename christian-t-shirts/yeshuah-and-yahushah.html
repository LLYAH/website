What are Yeshuah and Yahushah t-shirts?

These shirts use the Hebrew names rather than the Greek and English forms most English Bibles carry. Yeshuah and Yahushah are transliterations of the name rendered in English as Jesus, and Yahweh and YAH of the name rendered as LORD. For many believers, using the Hebrew name is a way of holding on to what translation smooths over.

Names in this collection

  • Yeshuah — a common transliteration of the Hebrew name of Christ.
  • Yahushah — a fuller transliteration used in Sacred Name congregations.
  • YAH — the shortened form of the divine name, as in halleluYAH.
  • Yahweh — the four-letter divine name rendered in English letters.
  • Paleo-Hebrew script — the name set in the ancient letterforms.

How the names are set

Hebrew transliterations are unfamiliar to most English readers, so letterspacing and weight matter more here than on any other shirt in the shop. Names are set with generous tracking so they are read correctly the first time.

  • Wide letterspacing — so unfamiliar names are read, not guessed at.
  • Paleo-Hebrew and modern Hebrew script — set alongside the transliteration.
  • Transliteration with the English form — both names, one above the other.
  • Minimal chest placement — for everyday wear.
  • Full-front type — when the name is the entire design.

Sacred Name t-shirt questions, answered

What does Yeshuah mean?

It is a transliteration of the Hebrew name rendered in English as Jesus. The Hebrew root carries the sense of salvation or deliverance.

What is the difference between Yeshuah and Yahushah?

Both transliterate the same Hebrew name. Yahushah is a fuller rendering that preserves more of the divine name YAH at the start, and is used most in Sacred Name congregations.

What does YAH mean?

The shortened form of the divine name, the same YAH that appears at the end of halleluYAH.

What is paleo-Hebrew?

The older Hebrew script used before the square Aramaic letterforms modern Hebrew uses. Several designs set the name in it.

Why use the Hebrew name instead of Jesus?

For many believers it is a way of holding to the name as it was originally spoken rather than as translation rendered it. Both forms are used across the wider church.
